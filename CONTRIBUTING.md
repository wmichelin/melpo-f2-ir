# Contributing

Useful contributions include independent confirmation on the exact MELPO model, original F2/F2-S captures, Timer duration/cancellation tests, and DIY long-press behavior.

Please report:

1. Exact brand, model, ASIN if available, and whether the device is IR or Bluetooth.
2. Transmitter/receiver hardware, library/version, protocol, address, command, and bit-order convention.
3. Initial light state, exact sequence sent, and observed behavior. Distinguish fixed colors from Store recalls and changing effects.
4. Which functions were actually tested and which labels are inferred.

Do not relabel generic RGB codes as F2 based solely on appearance. Do not include camera images of private spaces, secrets, or personal file paths. Contributions are licensed CC0-1.0, consistent with LICENSE.
